Board-to-X Sync

A personal automation that shares Pins from my own Pinterest board to my own X (Twitter) account.

What it does

  1. Reads Pins from a single Pinterest board owned by the operator, using the Pinterest API.
  2. Posts selected Pin images and their text to the operator's own X account, using the X API, with a link back to the original Pin on Pinterest.

Who it's for

Board-to-X Sync is built and operated by an individual developer for their own personal use. It is not a public service, is not offered to other users, and only connects to the operator's own Pinterest and X accounts.

Pinterest API usage

  • Read-only access to the operator's own board and Pins (boards:read, pins:read)
  • Basic account information required for authentication (user_accounts:read)
  • The tool never creates, edits, or deletes Pins or boards, and never accesses other users' data.
