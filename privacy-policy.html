Privacy Policy — Board-to-X Sync

Last updated: September 27, 2026

Board-to-X Sync ("the tool") is a personal, single-user automation built and operated by an individual developer. This policy explains what data the tool accesses and how it is used.

1. Who this applies to

This tool is built for the personal use of its single operator only. It is not a public application, is not distributed to other users, and does not act on behalf of any Pinterest or X (Twitter) account other than the operator's own.

2. What data is accessed

Once a day, the tool reads the public RSS feed of a single Pinterest board owned by the operator. From each Pin in the feed it uses the Pin URL, title, and image URL.

The tool does not use the Pinterest API or the X API, does not log in to either service, and does not access any non-public data.

3. How the data is used

For each Pin that has not been notified before, the tool emails the operator a link that opens X's standard post screen with the Pin's title and URL filled in. Nothing is posted automatically: the operator reviews and posts each item manually.

On a mobile device, the operator can instead open the share page (share.html), which loads the Pin image through the image proxy images.weserv.nl and hands the image and text to the device's share menu. This happens entirely in the operator's browser. Posts made this way include a link back to the original Pin.

No data is sold, shared with advertisers, or provided to any third party.

4. Data storage

To avoid notifying the same Pin twice, the tool keeps a list of the URLs of Pins it has already notified (up to 300) in the operator's own automation infrastructure (Pipedream). No other data is stored. The notification emails are kept only in the operator's own mailbox.

5. Data retention and deletion

The list of notified Pin URLs is kept only while the automation is active. The operator may delete it at any time by removing the automation workflow and its data store.

6. No use of data for advertising or profiling

This tool does not use any accessed data for advertising, analytics resale, profiling, or any purpose other than the notification function described above.

7. Changes to this policy

This policy may be updated if the tool's functionality changes. The "Last updated" date above reflects the most recent revision.
