Privacy Policy — Board-to-X Sync

Last updated: September 27, 2026

Board-to-X Sync ("the tool") is a personal, single-user automation built and operated by an individual developer. This policy explains what data the tool accesses and how it is used.

1. Who this applies to

This tool is built for the personal use of its single operator only. It is not a public application, is not distributed to other users, and does not authenticate or act on behalf of any Pinterest or X (Twitter) account other than the operator's own.

2. What data is accessed

Via the Pinterest API, the tool reads (does not modify):

  • Pin data from a single Pinterest board owned by the operator (image URL, title, description, Pin ID, creation time) (boards:read, pins:read)
  • Basic account information required for API authentication (user_accounts:read)

The tool does not create, edit, or delete any Pins or boards, and does not access any data belonging to other Pinterest users.

Via the X API, the tool only creates posts (with images) on the operator's own X account. It does not read, collect, or analyze any X data.

3. What data is shared externally

Selected Pin images and associated text are posted to the operator's own X (Twitter) account via the X API. Every post includes a link back to the original Pin on Pinterest (e.g. https://www.pinterest.com/pin/<Pin ID>/), making it clear that the content comes from Pinterest. Pin images are posted as-is, without filters, overlays, or other modifications.

No data is sold, shared with advertisers, or made available to any third party beyond this automated cross-posting between the operator's own accounts.

4. Data storage

The tool does not store any information obtained from the Pinterest API or the X API. Pin data is fetched from the API on each run, used only to create the post, and then discarded.

To avoid duplicate posts, the tool keeps a single value: the timestamp of its last run. On each run, only Pins created after that timestamp are posted. This timestamp is generated by the tool itself, is not Pinterest or X data, and is kept in the operator's own automation infrastructure (Pipedream).

API credentials for the operator's own accounts are held in Pipedream's credential storage and are never published or shared.

5. Data retention and deletion

Because no Pinterest or X data is stored, there is no such data to retain. The operator may delete the last-run timestamp and all credentials at any time by removing the automation workflow, and may revoke the tool's access at any time from Pinterest and X account settings.

6. No use of data for advertising or profiling

This tool does not use any accessed data for advertising, analytics resale, profiling, or any purpose other than the cross-posting function described above.

7. Changes to this policy

This policy may be updated if the tool's functionality changes. The "Last updated" date above reflects the most recent revision.
